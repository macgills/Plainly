# Plainly evaluation corpus

This directory is deliberately separate from browser integration tests. Browser tests prove that Plainly functions; these cases are for judging whether its rewrites are educationally acceptable.

`cases.json` contains short synthetic passages across subjects, plus facts/terms that should survive simplification and notes about the semantic risks a teacher should inspect.

Run the live corpus with:

```bash
AI_SECRET=sk-... npm run eval:live
```

This produces `evaluation-artifacts/plainly-teacher-review.html` and a machine-readable JSON copy. The same pack is generated by the live GitHub Actions job using the repository secret.

## Review rubric

For every Level 1, 2 and 3 rewrite, a teacher should judge:

1. **Meaning** — are all important claims still true, with cause/effect and relationships intact?
2. **Difficulty** — is the text genuinely easier at the selected level without becoming childish or vague?
3. **Subject vocabulary** — are essential terms preserved and, where appropriate, explained without inventing information?
4. **Student readiness** — would you be comfortable giving this version to a student as a transformed version of the source?

The generated pack also shows mechanical warnings for obviously missing required terms, changed numeric facts and selected uncertainty markers. Those checks are guardrails, not a substitute for teacher judgement.

The initial cases are intentionally synthetic so the evaluation corpus can evolve independently of live website wording and copyright/licensing concerns. The next useful expansion is teacher-supplied material from real lessons, with notes on what a good rewrite must and must not change.
